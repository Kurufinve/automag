# Python dependencies of automag on Windows (64-bit, CPython 3.12).
#
#   python -m pip install -r requirements-windows.txt
#
# This is requirements.txt adapted for Windows.  Every package below was
# checked with
#
#   pip download --only-binary=:all: --platform win_amd64 \
#                --python-version 3.12 --implementation cp --abi cp312 \
#                -r requirements-windows.txt
#
# i.e. all of them have a win_amd64/cp312 wheel and nothing has to be compiled
# on the target machine.  Differences from the Linux list:
#
#   * gunicorn is POSIX-only (it installs, but it cannot serve on Windows and
#     automag never imports it - only the optional FireWorks web GUI does);
#   * dataclasses is a Python 3.7 backport, useless on 3.12;
#   * the build tools (pyinstaller, ninja) are appended at the end, because
#     this file is also what tools\build_cpu_bundle.bat installs for compiling
#     the bundle.
#
# The Prophet-V1-Mag calculator (`prophet_spin`) is optional and heavy (torch):
#
#   python -m pip install -r requirements-prophet-windows.txt
